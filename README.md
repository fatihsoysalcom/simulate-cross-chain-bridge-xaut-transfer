# simulate-cross-chain-bridge-xaut-transfer
This example simulates a simplified cross-chain bridge for a token like Tether Gold (XAUT). It demonstrates how assets are 'locked' on one blockchain (e.g., Ethereum) and 'minted' as a wrapped token (wXAUT) on another (e.g., Solana), and vice-versa.
